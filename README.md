# Массив динамического размера

В данном задании от вас требуется написать класс `vector`, являющийся упрощением класса `std::vector` из стандартной библиотеки и реализующий структуру данных "_массив динамического размера_".\
В массиве должны храниться элементы типа `test_element` (этот тип написан в тестирующей системе в файле test_element.h).

Если вы не знаете или плохо помните, что такое массив динамического размера, дальше будет описание и подсказки по реализации. Если помните отлично, можете перематывать до [следующего раздела](#требования-к-реализации).

### Что такое массив динамического размера

Массив динамического размера — это структура данных, которая хранит следующие поля:
- Массив некоторого размера, который может быть больше, чем количество реально хранимых элементов.
- Количество реально хранимых элементов.

В C++ вместо массива будет указатель на начало и длина. Обычно указатель на начало называется `data`, размер этого массива называется `capacity`, а количество реально хранимых элементов называется `size`.

То есть возможна такая ситуация: внутри `vector`'а выделен массив на 10 элементов, но реально хранимых в нём только 7. Тогда `data` будет указателем на участок памяти размера _10 * размер одного элемента_, `capacity` будет равен 10, а `size` будет равен 7.

В такой структуре данных можно эффективно добавлять элемент в конец, убирать элемент из конца и находить элемент по индексу.
- Находить элемент по индексу легко — надо всего лишь взять элемент с соответствующим индексом в указателе `data`.
- Чтобы убрать элемент из конца, надо всего лишь вызвать деструктор последнему элементу и уменьшить `size` на единицу: у нас и так количество реально хранимых элементов может быть меньше, чем размер массива.
- Чтобы добавить элемент в начало, надо сначала проверить, осталось ли там место (т.е. правда ли что `size` строго меньше, чем `capacity`). Если да, можно поместить новый элемент сразу за последним хранимым и увеличить `size` на единицу. Если нет, то нужно выделить новый массив с `capacity` побольше, скопировать в него старые элементы и вставить новый уже туда.

При этом, если каждый раз увеличивать массив вдвое (или в любую другую константу раз), **в среднем** каждая вставка будет осуществляться за константное время. По-научному это называется "амортизированное время работы O(1)".

### Требования к реализации

Для данного класса должны быть определены следующие операции:
- `std::size_t size() const` — возвращает размер `vector`'а (т.е. количество реально хранимых элементов).
- `bool empty() const` — возвращает `true`, если размер равен нулю.
- `std::size_t capacity() const` — возвращает текущий размер выделенной памяти.
- `test_element* data()` и `const test_element* data() const` — возвращают указатель на первый элемент `vector`'а.
- `test_element& front()` и `const test_element& front() const` — возвращают ссылку на первый элемент `vector`'а.
- `test_element& back()` и `const test_element& back() const` — возвращают ссылку на последний элемент `vector`'а.
- `test_element& operator[](std::size_t index)` и `const test_element& operator[](std::size_t index) const` — принимают индекс и возвращает ссылку на элемент `vector`'а с соответствующим индексом.
- Конструктор по умолчанию. Создаёт `vector` с `capacity` равным нулю.
- Деструктор. Вызывает деструкторы всем хранимым элементам и освобождает память, если выделял.
- Конструктор копирования. Копирует все элементы, хранимые в переданном `vector`'е. `capacity` получившегося `vector`'а должна быть равна `capacity` переданного.
- Копирующий оператор присваивания. Делает так, чтобы переданный вектор был равен текущему. Как конкретно это сделать, не специфицируется. Например, если `capacity` переданного `vector`'а меньше, чем у текущего, можно присвоить нужное количество элементов и вызвать деструктор или конструктор копирования у оставшихся. Но можно и безусловно сделать swap-trick.
- `void clear() const` — удаляет все хранимые элементы. Не влияет на `data` и `capacity`.
- `void push_back(const test_element& element)` — добавляет переданный элемент в конец `vector`'а. Амортизированная временная сложность данного метода должна быть константной.
- `void pop_back()` — удаляет элемент из конца `vector`'а. Этот метод не должен менять `data` и `capacity`.
- `void reserve(std::size_t new_capacity)` — если текущий `capacity` меньше `new_capacity`, перевыделяет память так, чтобы `capacity` был равен `new_capacity`.
- `void shrink_to_fit()` — если `capacity` больше `size`, перевыделяет память так, чтобы они были равны.
- `test_element* insert(const test_element* where, const test_element& element)` — вставляет переданный элемент перед элементом, на который указывает `where`. Если в качестве `where` передать указатель за последним элементом, вставляет в конец. Возвращает указатель на вставленный элемент. При вставке около конца амортизированное время работы должно быть константным.
- `test_element* erase(const test_element* where)` — удаляет элемент, на который указывает `where`. Возвращает указатель на элемент после удалённого. Если удалили последний элемент, возвращает указатель на элемент за последним оставшимся. Не влияет на `capacity` и `data`.
- Внешняя функция `void swap(vector& lhs, vector& rhs)` — меняет местами два `vector`'а. Должна работать за константное время и не копировать элементы.

При выполнении задания обратите внимание на следующее:
- `vector` с нулевым `capacity` не должен выделять динамической памяти. Для `vector`'а с `capacity` равным нулю `data` должен быть равен `nullptr`. В том числе это распространяется на `vector`, который стал иметь нулевой `capacity` после вызова метода `shrink_to_fit`.
- Не допускайте лишних копирований.
- Все методы, которые не могут бросить исключений, должны быть помечены модификатором `noexcept`.
- Все методы, которые могут бросить исключение, должны иметь сильную гарантию исключений. Т.е. если из операции вылетает исключение, состояние `vector`'а должно остаться прежним. В том числе не должны измениться `capacity` и `data`.
- Выделять память при помощи `malloc` или других функций из C API запрещено.
- Очевидно, использовать `std::vector` для реализации своего `vector`'а нельзя.

### Что может помочь вам с реализацией

Подсказки по реализации:
- Удобно создать конструктор от `capacity`: он может помочь Вам в реализации конструктора копирования.
- Могут помочь функции, работающие с неинициализированной памятью (например, `std::uninitizlized_copy_n`). Их список можно найти [по ссылке](https://en.cppreference.com/w/cpp/memory.html#Uninitialized_memory_algorithms) в разделе Uninitialized memory algorithms.
- У `test_element` небросающий `swap`, используйте это. При этом, очевидно, `swap`'ать можно только уже созданные элементы: вызывать их от неинициализированной памяти нельзя.
